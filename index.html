Text Formatting Issues

  • ⚠️ YEAR contained extra characters like parentheses and Roman numerals.
  • ⚠️ VOTES included comma separators for thousands.
  • ⚠️ Gross featured '$' prefixes and 'M' suffixes instead of raw numbers.

Structural Issues

The GENRE column had multiple genres grouped into a single comma-separated string, making genre-specific analysis difficult.


                    "Action, Adventure, Sci-Fi"

Cleaning Text Data

  • Regex: Extracted valid 4-digit years using (\d{4}).
  • String Replacement: Stripped commas, '$', and 'M' symbols.
  • Type Conversion: Converted cleaned text columns into numeric types for calculations.

Structuring the Data

  • Used Pandas' .str.split(',') and .explode() functions to split the GENRE column.
  • Transformed the dataset so each movie-genre pair has its own dedicated row (wide to long format).

The Final State

The data is now a clean, structured dataset saved as Cleaned_Dataset.csv.

Readiness for Analysis

  • ✅ YEAR, VOTES, and Gross are numeric.
  • ✅ With genres exploded, the dataset is fully prepared for feature extraction and machine learning predictions.
