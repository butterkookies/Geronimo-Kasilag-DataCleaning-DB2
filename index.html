Scope 5 • Cleaning Methods

Methods & Tools Used to Clean

  • 🔍
    Regex Year Extraction: Extracted exact 4-digit years from messy strings like (2021– ) or (2010–2022) using regex pattern r'(\d{4})'.
  • 🧹
    Numeric Formatting: Stripped commas , from VOTES and removed $ and M symbols from Gross revenue strings before numeric conversion.
  • 💥
    Genre Exploding: Splitted multi-genre values (e.g., "Action, Adventure") with .str.split(',') and used pandas .explode() to create dedicated row entries for clean grouping.
