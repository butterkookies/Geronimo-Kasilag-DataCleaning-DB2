# AI Agent Rules & Design Kit for Presentation

This file acts as the strict system prompt for any AI agent interacting with this `slides` folder to generate presentations. 

## Part 1: Content & Grading Rules
1. **Source of Truth:** `Kasilag_Geronimo_IT31A.ipynb` is the definitive source for all code, logic, and data.
2. **Data Set Title & Acquisition (Points 1 & 2):** 
   - A dedicated first slide must explicitly state the Data Set Title as `movies.csv` and the Acquisition Method as "Downloaded from Kaggle". 
3. **Cleaning Processes & Tools (Points 3, 4, 5):**
   - The presentation must include actual Python code snippets used (e.g., `df.isnull().sum()`, `df.drop_duplicates()`).
4. **After Cleaning & Conclusion (Points 6 & 7):**
   - Present "Before & After" metrics (e.g., row count changes) alongside a visual sample table of the cleaned DataFrame.
   - End with a Conclusion slide summarizing the final clean state of the data, followed by a 'Thank You'.

## Part 2: Presentation Design Kit (Entertainment & Visuals)
1. **Visuals First Mandate:** The presentation MUST NOT be a wall of text. Use engaging visuals, cinematic layouts, and multimedia (like actual movie posters) to make the slides entertaining.
2. **Cinematic Aesthetic:** The overall theme must be a "Netflix" cinematic style featuring a dark background (black/dark grey) and vibrant red accents to fit the movies dataset.
3. **Typography System:** Use universally available web fonts:
   - **Titles/Headers:** `Bebas Neue` (or similar bold cinematic font) in uppercase.
   - **Body Text:** `Inter` or `Roboto`.
4. **Code Layout:** Code should not dominate the screen. Present it stylishly as smaller overlays or alongside rich visual backgrounds.
5. **Assets:** Always look in the `assets/` folder for images (e.g., movie posters) and use them to texture the background or build data visual grids.
